## Главные ноутбуки:

1) notebooks/train.ipynb -- обучение языковой модели Mistral с 45М обучаемых параметров. В этом ноутбуке также показаны примеры текстов датасета, эксперименты с токинезаторами, весь процесс обучения идемонстрация работы обученной модели.

2) notebooks/train-big-model.ipynb -- обучение языковой модели Mistral с 90М обучаемых параметров.

3) notebooks/demo.ipynb -- демонстрация работы обученной языковой модели Mistral с 90М обучаемых параметров.
