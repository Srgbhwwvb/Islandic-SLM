## Главные ноутбуки:

1. [`notebooks/train.ipynb`](notebooks/train.ipynb) — обучение языковой модели Mistral с 45М обучаемых параметров. В этом ноутбуке также показаны примеры текстов датасета, эксперименты с токенизаторами, весь процесс обучения и демонстрация работы обученной модели.

2. [`notebooks/train-big-model.ipynb`](notebooks/train-big-model.ipynb) — обучение языковой модели Mistral с 90М обучаемых параметров.

3. [`notebooks/demo.ipynb`](notebooks/demo.ipynb) — демонстрация работы обученной языковой модели Mistral с 90М обучаемых параметров.
